# 皮肤配色重设计 · engine 批：派生引擎与配对法补全

- 改什么：ColorMath 追加对比度/on-color 纯函数（保留既有 HSV 成员）；新建 SecondaryColors 派生回填；SkinCatalog 合并尾部接线；scrim 令牌；PanelPalette 增 AccentText。
- 为什么：spec R1/R2/R3 —— text-on-accent 配对缺失（选中行白底白字）与次要面手拍失控（纯白死区盘）。

- 回滚方式：编译自动快照 `docs/changes/skin-color-redesign-engine.rollback.json`；一键还原同脚本 --rollback。
